# utilities

General-purpose utilities for Claude Code.

## Skills

| Skill               | Trigger                                                               | Description                                                                         |
| ------------------- | --------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| `gs:utilities:date` | "commits from last week", "logs from the last 3 hours", "30 days ago" | Calculate dates and datetimes from natural language using BSD date commands (macOS) |

## Installation

```
/plugin marketplace add gsong/claude-marketplace
/plugin install utilities@gsong-marketplace
```
